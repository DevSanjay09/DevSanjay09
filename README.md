<h2 align="center">🛰️ ISRO – NavIC Error Prediction</h2>

<div align="center">
  <img src="https://img.shields.io/badge/ISRO-NavIC-blue?style=for-the-badge" />
  <img src="https://img.shields.io/badge/Deep%20Learning-LSTM%20%7C%20Transformer-purple?style=for-the-badge" />
  <img src="https://img.shields.io/badge/FastAPI-Backend-green?style=for-the-badge" />
  <img src="https://img.shields.io/badge/Docker-Deployment-blue?style=for-the-badge" />
</div>

<br>

<p align="center">
  <b>NavIC Error Prediction using Deep Learning</b> is an ML project developed
  in collaboration with <b>ISRO</b> to predict satellite positioning and clock errors.
</p>

<p align="center">
  The system uses historical <b>GNSS GEO/GSO and MEO satellite data</b> to forecast
  errors at <b>15-minute intervals</b>. We experimented with
  <b>LSTM, GRU, Transformer, and Hybrid LSTM-Transformer architectures</b>.
</p>

<p align="center">
  The predicted errors can be used for <b>proactive correction</b> of navigation
  signals, helping reduce positioning inaccuracies instead of relying only on
  reactive ground-based corrections.
</p>

  🔹 LSTM / GRU / Transformer &nbsp; • &nbsp;
  🔹 FastAPI &nbsp; • &nbsp;
  🔹 Docker
</p>
